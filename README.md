ÁTOMO LAB 

Laboratorio de química en 3D: saca átomos de la tabla periódica, júntalos y forma moléculas reales.
Agítalas para calentarlas, lánzalas, llévalas al mechero… y provoca reacciones.

- Pantalla táctil / mouse: toca o arrastra elementos; dos dedos = dos átomos a la vez.
- Modo manos: usa la cámara y pellizca (pulgar + índice) para agarrar átomos.
- VR / AR: Meta Quest (navegador Meta) o Apple Vision Pro (Safari), con seguimiento de manos.
